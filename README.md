# Ecommerce Full Stack Application

## Tech Stack
- Frontend: ReactJS
- Backend: NodeJS / ExpressJS
- Database: MySQL / PostgreSQL

## Features
- User Authentication
- Role Based Access
- Admin Dashboard
- Product Management
- Store Rating System
- Search and Filtering
- JWT Authentication

## Project Structure

ecommerce/
│
├── frontend/
└── backend/

## Setup Instructions

### Frontend
cd frontend
npm install
npm start

### Backend
cd backend
npm install
npm start
